## Відкриті рішення власника

1. Широкий ринок чи внутрішній інструмент «Шляху Потоку»? (визначає Фази 5–7)
2. Preact для UI-оболонки чи чистий vanilla TS? (ADR-003)
3. Монетизація і тарифи — підтвердити (поточні цифри — гіпотеза, не дослідження ринку).
4. Де живе код поточного рендер-сервера `flow-edit.116-203-217-173.sslip.io`? Потрібен для F0-9.
5. Бренд/домен для продакшну.
6. Ліцензія коду (MIT / комерційна)?
7. Скільки виконавців і який бюджет? (від цього залежать терміни в роадмапі)

## Що документація НЕ покриває (свідомо)

- UX/UI-макети (екрани, мобільний layout) — потрібен окремий етап дизайну перед Фазою 2.
- Дослідження ринку і конкурентів — таблиця в PRD зроблена з загальних знань, не з перевірки.
- Каталог шаблонів і візуалів — тільки кількість і приклади.
- Окремі файли ADR (`docs/adr/`) — таблиця рішень є в 03-ARCHITECTURE.
- Код сервера рендеру не вивчався (його немає в репозиторії).
