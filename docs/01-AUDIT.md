## 1. Що це зараз

Однофайловий браузерний редактор вертикального відео 9:16 (1080×1920) під контент
«Шлях Потоку». Без збірки, без залежностей. Хостинг — GitHub Pages.
Експорт MP4 — на зовнішньому сервері `flow-edit.116-203-217-173.sslip.io`,
**код якого відсутній у репозиторії**.

### Функціонал, що працює

| Зона | Що є |
|---|---|
| Документ | `{version, meta, tracks[], items[]}`, autosave у `localStorage` (`flowedit.v1`) |
| Елементи | 14 пресетів: title, subtitle, glow, rays, vignette, particles, embers, cross, line, vortex, rings, nebula, constellation, grain (canvas) |
| Таймлайн | 1 доріжка, переміщення/ресайз кліпів, зум, «Увесь», playhead, ruler-scrub |
| Редагування | дубль, розріз по курсору (з `anchor`, анімація продовжується), видалення |
| Інспектор | слайдери/колір/селект за `fields` пресета |
| Історія | undo/redo (60 кроків) |
| Проєкт | JSON export/import/copy, очистити |
| Експорт | POST `/api/export` → полінг `/api/status/:id` → посилання на MP4 |
| Клавіші | Space, Delete/Backspace, Ctrl+Z / Ctrl+Shift+Z, ←/→ (Shift = 1 с) |
| API | `window.FLOW` — для headless-рендера (`?export`, `exportMode`, `setTime`) |

### Сильні сторони архітектури (зберегти!)

1. **`applyTime(t)` — єдина точка кадру** (L668). Анімації WAAPI на паузі, `currentTime`
   ставиться вручну → детермінований кадр → WYSIWYG-експорт.
2. **Реєстр `REG`** (L288) — новий тип елемента = один запис.
3. **Seeded random** (L268) — однаковий `id` дає однакову картинку завжди.
4. **`mut(fn)`** (L700) — одна точка мутації (undo + save + rerender).
5. Обхід бага WAAPI з easing → easing переноситься в keyframes (L611–624).

## 3. Функціональні прогалини (відносно мінімального продукту)

- Немає **медіа**: зображення, відео, **аудіо/музика** (для вертикального відео — критично).
- Немає **кейфреймів** для довільних властивостей (лише вшиті анімації пресетів).
- Немає **переходів** між сценами, **шаблонів**, **пресетів стилю**.
- Немає **мульти-виділення**, copy/paste, snapping, магнітного таймлайну.
- Немає **шрифтів** (лише системний), багаторядкового тексту з розміткою, субтитрів (SRT).
- Немає **кількох проєктів**, хмарного збереження, акаунтів.
- Немає **тестів**, CI, лінтера, версіонування релізів, аналітики, логування помилок.
- Немає **onboarding**: новий користувач бачить порожній чорний екран.

## 4. Технічний борг

- 1151 рядок в одному IIFE: CSS + HTML + 14 пресетів + движок + UI.
- Рендер через рядкові шаблони `innerHTML` (повний remount на кожну зміну параметра).
- Стан у замиканнях (`sel`, `playhead`, `dpps`), UI оновлюється вручну.
- Немає типів / схеми документа.

## 5. Висновок

Ядро (детермінований час + реєстр + WAAPI) — **правильне і варте збереження**.
Усе навколо — прототип. Шлях у продукт: модуляризація без зміни ядра → виправлення
P0/P1 → багатодоріжковий таймлайн + маніпуляція на сцені + аудіо → відкритий
відтворюваний рендер-сервер → шаблони і акаунти.
