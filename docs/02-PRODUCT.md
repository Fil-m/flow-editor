# 02 · Продукт (PRD)

> Статус: чернетка для узгодження. Пункти з позначкою **[?]** — рішення власника.

## 1. Одним реченням

**Flow Edit** — браузерний редактор атмосферних вертикальних відео (Reels / Shorts / TikTok)
з бібліотекою «живих» процедурних візуалів: світло, частинки, туманності, символи, текст —
без стоків, без After Effects, з телефона.

## 2. Проблема

Автори медитативного, духовного, мотиваційного, музичного контенту роблять короткі
вертикальні відео з текстом на гарному фоні. Варіанти зараз:

| Інструмент | Біль |
|---|---|
| CapCut / InShot | стокові фони однакові в усіх, водяні знаки, складно зробити «атмосферу» |
| Canva Video | шаблонно, анімації примітивні |
| After Effects | дорого, складно, не з телефона |
| Генеративні AI-відео | непередбачувано, немає контролю над текстом і таймінгом |

## 3. Цінність

1. **Процедурна графіка** — нескінченна, чиста, без артефактів стиснення, будь-який колір.
2. **Детермінований кадр** — прев'ю = експорт (WYSIWYG).
3. **Mobile-first** — повноцінно працює з телефона.
4. **Швидкість** — від ідеї до MP4 за 5 хвилин через шаблони.

## 4. Аудиторія та персони

| Персона | Опис | Ключова задача |
|---|---|---|
| **Автор-практик** (основна) | веде Instagram/Telegram про медитацію, дихання, віру, психологію | 3–5 відео/тиждень: цитата + атмосфера + музика |
| **Музикант** | треба візуалізатор під трек | фон під аудіо, реакція на біт |
| **SMM-фахівець** | веде кілька акаунтів | шаблони з брендом, пакетний експорт |
| **Сам власник** («Шлях Потоку») | перший користувач | внутрішній контент-конвеєр |

План нижче розрахований на широкий ринок, але Фази 0–2 корисні в обох випадках.

## 5. Обсяг MVP (публічний запуск)

### Must have
- Кілька доріжок, z-порядок, перетягування елементів на сцені (move/scale/rotate).
- Аудіо-доріжка (завантажити трек, waveform, обрізати, fade) — експортується в MP4.
- Зображення як елемент (фото/лого).
- Кейфрейми базових властивостей (x, y, scale, rot, alpha) з easing.
- Текст: Google Fonts (набір ~20), багаторядковий, ефекти появи (по літерах / словах).
- 10+ готових шаблонів; онбординг «почни з шаблону».
- Кілька проєктів (IndexedDB), автозбереження, дублювання.
- Надійний експорт 1080×1920 MP4 (H.264 + AAC) з чергою і лімітами.
- Формати: 9:16, 1:1, 4:5, 16:9.
- Безпечна модель документа (схема + валідація + міграції).

### Should have
- Субтитри з SRT / автоматичні з аудіо (Whisper).
- Аудіо-реактивні візуали (амплітуда/біт → параметр).
- Переходи між сценами.
- Акаунт + хмарне збереження.
- Експорт у браузері (WebCodecs) для коротких відео без сервера.

### Won't have (поки)
- Монтаж довгого відео, кольорокорекція, хромакей, мультиплеєрне редагування.

## 8. Нефункціональні вимоги

- **Продуктивність:** 60 fps прев'ю для 30 елементів на mid-range Android (Pixel 6a / Galaxy A54).
- **Сумісність:** Chrome/Edge 110+, Safari 16.4+, Firefox 115+; iOS Safari — повна підтримка редагування.
- **Надійність:** жодної втрати даних (автозбереження ≤ 1 с, відновлення після крешу).
- **Безпека:** документ — дані, а не код; жодного неекранованого вводу в DOM; CSP.
- **Доступність:** клавіатурна навігація, `aria-label`, контраст WCAG AA для UI.
- **Локалізація:** uk (основна), en; далі de, pl.
- **Приватність:** GDPR — медіа користувача видаляються з сервера рендера ≤ 24 год.
