# 07 · Безпека, юридичні питання, вартість

## 1. Модель загроз (коротко)

| Актив | Загроза | Вектор | Заходи |
|---|---|---|---|
| Браузер користувача | XSS | імпортований/розшарений JSON (B1, B22), шаблони, публічні посилання | схема + санітизація, без `innerHTML`, CSP, відмова від inline-скриптів |
| Рендер-сервер | RCE / SSRF / DoS | шкідливий документ у headless Chromium (B23); величезні проєкти | валідація, ізоляція мережі, ліміти (2 МБ, 180 с, 500 items), cgroup-ліміти CPU/RAM, таймаут задачі |
| Вартість | зловживання API | відкритий `/api/export` (B27) | токени, rate-limit, квоти за тарифом, CORS-allowlist |
| Дані користувачів | витік медіа | публічні S3-URL | presigned URL з TTL, неугадувані ключі, видалення ≤ 24 год |
| Акаунти | перебір/фішинг | email-логін | magic-link, rate-limit, Apple/Google OAuth |
| Платежі | підробка вебхуків | Stripe | перевірка підпису вебхуків, ідемпотентність |

## 2. Юридичне (потребує консультації юриста — це не юридична порада)

| Тема | Ризик | Дія |
|---|---|---|
| Авторські права на музику | користувачі вантажать чужі треки → претензії до платформи | ToS: відповідальність користувача; процедура DMCA/notice-and-takedown; не зберігати результати довше TTL; не пропонувати «безкоштовну музику» без перевіреної ліцензії |
| Шрифти | ліцензії | лише OFL/Apache (Google Fonts), self-hosted; список із ліцензіями в репозиторії |
| Ліцензія коду | її немає (B29) | обрати: MIT/Apache (відкритий) або «All rights reserved» (комерційний) — **рішення власника** |
| GDPR (власник у DE) | персональні дані, cookies, хмара | Privacy Policy, DPA з хостингом/Stripe/Supabase, Impressum, право на видалення (експорт+delete акаунта), аналітика без cookies |
| Умови контенту | релігійні/політичні матеріали, шкідливий контент | ToS-обмеження, форма скарги |
| Податки | продаж SaaS в ЄС | VAT OSS / Stripe Tax |
| Назва/бренд | «Flow Edit» — загальна | перевірка товарних знаків (EUIPO, USPTO) до запуску |

## 3. Орієнтовна вартість (EUR/міс., потребує перевірки актуальних тарифів)

| Стаття | Старт | Після зростання |
|---|---|---|
| VPS для рендеру (Hetzner 4–8 vCPU) | 15–40 | 100+ (кілька воркерів) |
| Об'єктне сховище + трафік | 1–5 | 20+ |
| Redis, Sentry, моніторинг | 0–25 | 50 |
| Auth/БД (Supabase) | 0–25 | 25+ |
| Домен, e-mail | 2 | 5 |
| Stripe | 1.5 % + 0.25 € за транзакцію | — |
| **Разом** | **≈ 20–100** | **≈ 200+** |

Собівартість рендера: ~1–2 хв CPU на відео 30 с → при 40 € / 4 vCPU це порядку ≤ 0.01–0.02 € за експорт.
Точку беззбитковості тарифів (див. 02 §6) варто порахувати після бенчмарка Ф4.
