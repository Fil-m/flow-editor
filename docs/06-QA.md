# 06 · Якість і тестування

## Піраміда

| Рівень | Інструмент | Що покриває |
|---|---|---|
| Unit | Vitest | schema/migrate, санітизація, keyframes/easing, команди undo, seeded RNG |
| Golden frames | Playwright + pixelmatch | кожен пресет у 4 моменти часу; 5 еталонних проєктів |
| E2E | Playwright (Chromium, WebKit, mobile viewport) | сценарії нижче |
| Сервер | Vitest + supertest; навантажувальний k6 | API, ліміти, черга |
| Ручний | чек-лист перед релізом | реальні телефони |

## Ключові e2e-сценарії

1. Додати заголовок → змінити текст → відтворити → undo/redo.
2. Розрізати кліп → права частина продовжує анімацію з того ж кадру (порівняння кадрів).
3. Імпорт JSON v1 → міграція → експорт JSON → повторний імпорт (round-trip).
4. Імпорт шкідливого JSON (XSS-пейлоади) → жодного виконання скрипта (`page.on('dialog')` не спрацьовує).
5. Перезавантаження сторінки посеред редагування → стан відновлено.
6. Експорт 5 с чернетки → отримано MP4, тривалість 5.0 с ± 1 кадр.

## Ручний чек-лист релізу

- [ ] Android Chrome (mid-range), iPhone Safari, Desktop Chrome/Firefox/Safari.
- [ ] Touch: drag кліпа, ресайз, scrub, pinch на сцені.
- [ ] Відкрити проєкт попередньої версії.
- [ ] Експорт чернетки і фіналу, відтворення файлу в Instagram (завантажити в чернетки).
- [ ] Офлайн: редагування працює без мережі.
- [ ] Lighthouse: Performance ≥ 85 (мобільний), Accessibility ≥ 90.

## Бюджети продуктивності

| Показник | Бюджет |
|---|---|
| JS (gzip), початкове завантаження | ≤ 150 КБ |
| LCP (4G, mid-range) | ≤ 2.5 с |
| Кадр прев'ю, 30 елементів | ≤ 16 мс (desktop), ≤ 22 мс (Pixel 6a) |
| Перемикання параметра в інспекторі → оновлення сцени | ≤ 50 мс |

## Definition of Done (для кожної задачі)

- Код пройшов lint + typecheck, покритий тестом відповідного рівня.
- Немає нових `innerHTML` з даними користувача.
- Схема змінилась → є міграція + фікстура.
- Оновлено документацію / CHANGELOG.
- Перевірено на мобільному viewport.
