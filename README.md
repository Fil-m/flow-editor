# Flow Edit

Міні-редактор вертикального відео (9:16) для контенту «Шлях Потоку»: таймлайн,
бібліотека CSS-візуалів, інспектор параметрів, розріз по курсору, експорт у MP4.

**Відкрити:** https://fil-m.github.io/flow-editor/

## Що працює тут

- редагування, прев'ю, таймлайн, undo/redo — повністю в браузері;
- проєкти зберігаються в `localStorage` цього домену;
- експорт MP4 **не** виконується в браузері: сторінка надсилає проєкт на сервер
  (`flow-edit.116-203-217-173.sslip.io`), той рендерить кадри headless-браузером
  і віддає готовий файл. Якщо сервер недоступний — редагування працює, експорт ні.

## Перенести проєкт

Кнопка **⋯ → ⬇ Зберегти JSON** на одному пристрої, **⬆ Відкрити JSON** на іншому.
Проєкти не синхронізуються між доменами автоматично.

## Джерело

Файл `index.html` самодостатній: без збірки, без зовнішніх бібліотек, без CDN.
